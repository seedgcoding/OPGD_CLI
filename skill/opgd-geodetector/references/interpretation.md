# OPGD 结果解读指南

向用户解释分析结果时参考本指南。四大探测器各回答一个问题：

| 探测器 | 回答的问题 | 关键数字 |
|--------|-----------|----------|
| 因子探测 | 哪个因子对 Y 的解释力强？ | q 值、p 值 |
| 交互探测 | 两因子叠加，解释力变强还是变弱？ | q(X1∩X2)、交互类型 |
| 风险探测 | 因子的高低区间，哪里 Y 更高？ | 分层均值、显著性 |
| 生态探测 | 两因子解释力的差异可靠吗？ | F 检验显著性 |

## 因子探测：q 值与 p 值

- **q 值（0~1）= 该因子能解释 Y 空间差异的比例**。q=0.89 即"解释 89% 的空间分布差异"。
- q > 0.5 相当强；q < 0.1 弱。**排序比绝对值重要**：排第一的是主导因子。
- **p < 0.05 才可下结论**；p ≥ 0.05 的 q 值可能只是随机波动，不要据其下结论。
- 向用户汇报时给出排序 + 主导因子 + 显著性，例如："X1 是主导因子（q=0.896, p<0.01），解释力显著高于 X2（q=0.258）"。
- **两因子 q 值接近（差距 < 0.05）时，不要断言"显著强于"**——解释力差异是否可靠需要生态探测（F 检验）确认，稳妥表述为"解释力相当，X 略占优"。

## 交互探测：五种类型

判断规则（q1、q2 为单因子 q 值，q12 为交互 q 值）：

| 交互类型 | 条件 | 人话 |
|----------|------|------|
| 双因子增强 | q12 > max(q1,q2) 且 q12 < q1+q2 | 1+1>2，机制互补 |
| 非线性增强 | q12 > q1+q2 | 远超简单相加 |
| 非线性减弱 | q12 < min(q1,q2) | 互相拖后腿（机制重叠） |
| 单因子减弱 | min(q1,q2) < q12 < max(q1,q2) | 比强者略差、比弱者强 |
| 相互独立 | q12 ≈ q1+q2（误差 <1e-6） | 互不干扰 |

汇报要点：找 q(X1∩X2) 最大的组合重点解读；"增强"说明两因子互补，"减弱"说明测的是同一种东西。

⚠️ 常见混淆：**和 q1+q2 比**——没超过相加值是"双因子增强"，超过了才是"非线性增强"，论文里别写混。

## 风险探测

分层两两 t 检验。读法：看均值列的梯度 + 显著性。例："X1 处于低分层的区域 GDP 均值（27.5）显著低于高分层（46.4，p<0.05），存在明显梯度关系"。

## 生态探测

F 检验两因子解释力差异是否可靠。"显著"时才能说"X1 的解释力显著强于 X2"。

## 最优离散参数（optimal_params）

按变量给出 `{method, bins, q_value}`。这是 OPGD 的核心卖点——审稿人问"分级数为什么这么定"时的答案。

## 论文句式模板（用户是科研场景时主动提供）

**因子探测：**
> 因子探测结果显示，X1 是解释 Y 空间分异的主导因子（q = 0.896，p < 0.01），解释力显著高于 X2（q = 0.258，p < 0.05）；X3 的解释力较弱且未通过显著性检验（q = 0.016，p = 0.624）。

**交互探测：**
> 交互探测结果表明，任意两因子交互后的解释力均高于单因子，以双因子增强为主。其中 X1 与 X2 交互后解释力达 0.990，表明二者对 Y 空间分异的作用机制互补。

**最优参数（方法部分）：**
> 采用基于最优参数的地理探测器（OPGD, Song et al., 2020），对连续型自变量遍历等间距、分位数、自然断点、几何间隔与均值标准差 5 种离散化方法及 3~8 级分级数组合，以 q 值最大者为最优离散化方案，克服传统 Geodetector 人为分级的主观性。

**风险探测：**
> 风险探测显示，X1 低分层区域的 Y 均值（27.5）显著低于高分层区域（46.4，p < 0.05），存在明显的分层梯度关系。

**生态探测：**
> 生态探测结果表明，X1 对 Y 空间分异的解释力显著强于 X2（p < 0.05）。
